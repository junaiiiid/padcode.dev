Formulas for Swift developers

PadCode's formulas are Swift-style expressions that fill in real SwiftUI views. What carries over from Swift, what's different, and the formula function for each Swift method you'd reach for.

Every component in PadCode is a real SwiftUI view: a Text is SwiftUI's Text, a Column is a VStack, a Switch is a Toggle. PadCode draws them from your app's data, without compiling any code. The values that change go in formulas: short expressions, written much like Swift, that PadCode works out as your app runs.

If you know Swift, you can read formulas already. This page is what's the same, what isn't, and the function to use for each Swift method you'd reach for. For everything formulas can do, see the formula language reference and every function.

#A formula is one expression

A formula is a single expression, like the right-hand side of a Swift let: total * (1 + tip) / people. It has no statements, no let or var, no closures and no control flow. What would be statements in Swift are actions in PadCode: Set Value for an assignment, If for an if, Repeat for Each for a for loop. Formulas fill in their settings.

SwiftIn a formula

== != < <= > >=The same

#What's different

In SwiftIn a formula
Int, Double, CGFloat…One kind of number: 7 / 2 is 3.5, and % works with decimals.
"Total: \(total)"No interpolation inside a formula: join with +, as in 'Total: ' + total. In a text setting, braces do it: Total: {total}. See Text with values.
"a" + 1 is an error+ joins text with anything: 'Item ' + 1 is "Item 1".
user?.address?.cityNo ?.: user.address.city is already safe, and is null when any part is missing.
nilnull.
a ?? 0 > 5 means a ?? (0 > 5)……and in a formula too, because ?? is looser than comparisons. Write (a ?? 0) > 5.
1 < 2 < 3 doesn't compileIt's read as (1 < 2) < 3, which compares true with 3: an error. Use &&.
if x needs a Bool!, &&, || and conditions take any value, and decide what counts as true: 0, '', [] and null are false.
sin(.pi / 2)Angles are in degrees: sin(90) is 1.
name.count, name.uppercased()No methods or properties of your own values: use free functions, like count(name) and uppercase(name). The table below has them all.
{ $0.done }No closures: list functions take a formula with it as each item, like filter(todos, !it.done).
struct, Dictionary(…)No new records in a formula: a record comes from a variable, an API's answer, or parseJSON('{"a": 1}').

#Where formulas go

  • A setting's ⚡︎ button → Formula… links any setting to one. The setting shows the formula after ƒ.
  • Text with braces: Hello, {name}! and Total: {currency(total)}.
  • Steps' settings, like Set Value's new value or If's condition.
  • Describe it, on Pro, writes one from your words. See Writing a formula from words.
