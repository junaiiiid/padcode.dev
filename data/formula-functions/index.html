Formula functions

Every function a formula can use: what it takes, what it gives back, and examples.

Functions do work inside a formula: round(total, 2), uppercase(name), count(tasks). Write the function's name, then what it works on in brackets, separated by commas. A name ending in ? can be left out. The whole language is in Formula language reference.

#How to read this page

Each table lists a function the way you write it, what it does, and what it gives back.

  • round(number, places?) takes a number and, if you like, how many decimal places. The words in brackets say what goes there; you put your own values or formulas in their place: round(total, 2).
  • ? after a word means you can leave that value out: round(total) rounds to a whole number.
  • ... means as many values as you like: max(a, b, c). min and max also take one list: max(scores).
  • it is each item of the list, in turn, inside filter, find, map, sort, any and all: filter(tasks, !it.done).
  • Text values take anything and use it as it would print, so uppercase(5) is fine. Number values must be numbers: turn typed text into one with number(…) first.
  • Dates are text like 2026-10-28 or 2026-10-28T14:30:00Z. now(), today() and the date functions give back the second form, in UTC, and formatDate writes one out for people to read.
  • Angles are in degrees, as the Rotation modifier takes them: sin(90) is 1. Colors are text like '#5B6CFF', as the color picker writes them.
  • Examples use the sample data on the formula language page: total is 120, name is "Sam", scores is [70, 95, 82, 95], tasks is a list of three tasks, and so on. Results are written the way you'd write the value in a formula: text in quotes, lists in square brackets. Money, percentages, dates and times are shown for an iPad set to English (US), in New York time.

Functions go inside each other, and the inner one is worked out first. In the Formula sheet, tap a function to add it with its opening bracket.

#Worked examples

These come from apps like an invoice maker and a to-do list. Each builds on functions from the tables below.

Add up an invoice. items is a list of records, each with qty and rate:

currency(sum(map(items, it.qty * it.rate)))

map turns each line into its amount (1 × 1200 and 4 × 85 give 1200 and 340), sum adds them up (1540), and currency writes it as money, like $1,540.00, in the iPad's currency and the way its region writes money. Add a currency code to choose one: currency(…, 'EUR').

Count what's left to do. tasks is a list of records with a True / False field done:

count(filter(tasks, !it.done))

filter keeps the tasks that aren't done, and count says how many. In text: {count(filter(tasks, !it.done))} left.

Search a list. search is the variable a Text Field keeps:

filter(products, contains(it.title, search))

contains ignores capital letters, so "phone" finds "iPhone". While search is empty, every product matches, so the whole list shows. Link a Repeater's Data to this formula to show the results.

Newest first. history is a list of records with a Date & Time field date:

sort(history, it.date, true)

The second value says what to sort by, and true puts the largest first. Dates sort by their time, so the newest comes first. first(sort(history, it.date, true)) gives only the newest record.

A due date and the days left. dueDays is a Whole Number, like 14:

formatDate(addDays(today(), dueDays), 'long')

addDays counts forward from the start of today, and formatDate writes the date out in full, the way the iPad's region writes dates. For the days left until a date variable dueDate, use daysBetween(today(), dueDate): it's negative once the date has passed.

A percentage that can't divide by zero.

percent(count(tasks) == 0 ? 0 : count(filter(tasks, it.done)) / count(tasks), 0)

With 1 task done out of 3, it gives 33%. The ? : checks for an empty list first, because dividing by count(tasks) when it's 0 is an error ("Can't divide by zero."). The last value, 0, is how many decimal places percent shows.

#round(number, places?)

Rounds to a number of decimal places (whole number if left out).

Gives back: Number

Takes

ValueWhat it isKindRequired
numberThe number to round.NumberYes
placesHow many decimal places to keep.NumberNo: 0, a whole number

Examples

FormulaResult
round(total / 7, 2)17.14
round(2.5)3
round(-2.5)-3
round(1.005, 2)1
round(1234.5, -2)1235

Good to know

  • Halves round away from zero: 2.5 becomes 3, and -2.5 becomes -3.
  • places is itself rounded to a whole number and kept between 0 and 15. A negative places counts as 0, so round can't round to tens or hundreds.
  • Some decimals are stored a hair below what you typed, so round(1.005, 2) gives 1, not 1.01.
  • The answer is a number, so zeros at the end don't show: round(2.5, 2) gives 2.5. To show 2.50, use fixed.
  • Text isn't rounded, even when it looks like a number: round(qtyText) is an error: “round needs a number, not text.” Use round(number(qtyText)).
