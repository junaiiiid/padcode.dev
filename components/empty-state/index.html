Empty State

A friendly message for when there's nothing to show yet.

In the Library: Components → Status · Needs PadCode Pro

#When to use it

Use an Empty State where a list or a screen has nothing to show yet: no tasks, no search results, no messages. A friendly message with an icon tells people what to do, instead of leaving a blank space.

#How to use it

  1. Add an Empty State where the list or content goes.
  2. Type Title and Description.
  3. Tap Icon to open Choose an Icon and pick one.
  4. Open Show & enable and set Show when to a condition that's true while there's nothing to show, like isEmpty(tasks).
  5. Give the list the opposite Show when: !isEmpty(tasks).

#Example

A to-do app has an Empty State with Title No tasks yet, the checklist icon, and Description Tap + to add your first task.. With Show when set to isEmpty(tasks), it shows until the first task is added, then the list takes its place.

#Good to know

  • Text + Image shows one of your own pictures (from Assets) instead of an icon. Custom content + Description + Actions has places for your own views: the title, the words under it, and buttons, like a Try again Button.
  • While its Show when is false, the canvas still draws it, faded, so you can select it.

#Add it

In the Library's Components tab, find Empty State under Status (or search for it) and either:

  • Tap it. It goes inside the selected container, at the end; right after the selected view, if that isn't a container; or at the bottom of the screen when nothing is selected.
  • Drag it onto the canvas, to exactly where you want it. A line shows where it will land.

#Made of

The Made of menu, at the top of its settings, picks which pieces it has. Switching keeps the settings the versions share.

  • Custom content + Description + Actions
  • Text + Image
  • Text + Icon (where it starts)

#Settings

In the Inspector's Style tab, top to bottom. Tap ⓘ next to a setting in the app for the same help.
