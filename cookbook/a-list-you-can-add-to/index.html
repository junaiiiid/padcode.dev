A list you can add to

Build invoice line items: type a line, add it to a list, remove it again, and add up the total.

What you'll build: the line items of an invoice, like the Invoice Maker app. People type a description, pick a quantity and type a rate, then tap Add line. Each line shows its amount and a Remove button, and the total adds itself up.

What you'll learn:

  • Keep a list of records in one variable.
  • Show one row per item with a Repeater.
  • Add an item made of what people typed.
  • Remove the row whose button was tapped.
  • Add up a list with a formula.

#The variables

NameTypeStarting value
itemsList of RecordsOne example line
draftDescriptionTextEmpty
draftQtyWhole Number1
draftRateTextEmpty

The draft… variables hold what's being typed, before it becomes a line.

#Steps

#Make the list

  1. In the Library (the left panel), open Data & Logic.
  2. Tap Add variable, then List of… → Records. It's called items. (If that name was taken, it gets a number; tap the name to change it.)
  3. Under the list, tap Add item. The new record has no fields yet: tap Add field four times and pick Text, Text, Decimal Number and Decimal Number. They're named field1, field2…; tap each name and change them to id, description, qty and rate.
  4. Fill in an example line: 1, Logo design, 1, 400.
  5. Add the other three variables from the table with Add variable. Each is named after its type (text, count…), so tap each name and type the one from the table. Set draftQty's starting value to 1.
Tip

Keep at least one item in the list while you build. The ⚡︎ menu's Repeater item section lists the fields of the list's first item, so it's empty while the list is.

#Show one row per line

  1. Tap the empty canvas around the device, so nothing is selected.
  2. In the Library's Components tab, tap Column (under Layout). It goes at the bottom of the screen and stays selected.
  3. Tap Row. It goes inside the Column.
  4. Tap Text, Spacer, Text and Button, in that order. Each one lands after the one before it, inside the Row.
  5. Select the Column again (tap it in Layers). In the Inspector's Data tab, tap Repeat for each item… next to Repeat, and choose For each in items. The Row is now inside a Repeater, which repeats it once per line.
  6. Select the first Text in the row. Next to Content, tap ⚡︎ → Repeater item → description.

  7. Select the second Text and type this into Content:

    {currency(item.qty * item.rate)}

  8. Select the Button and change its Title to Remove.

item is the line this copy of the row is showing. currency(…) writes a number as money in the iPad's currency; add a code to pick one, like currency(item.rate, 'EUR').

#Remove a line

  1. With the Remove button selected, open the Actions tab. When Tapped is already picked.
  2. Tap Add action and choose Remove from List (under Data). Tap the step to open it.

  3. Set State to items and Where to:

    it.id == item.id

Where starts as true, which would remove every line, so change it before you try the button.

Note

The Where box may say "There's nothing called it." You can leave it: it (each item in the list) and item (this row's line) only exist while the step runs. Issues doesn't count them as errors.

#Type a new line

  1. Tap the empty canvas, then add a Text Field. In its Text menu (in the Style tab, or the Data tab), pick draftDescription, and set its Title to Description. The title shows in the empty field.
  2. Add a Stepper. Set its Title to Qty {draftQty}, its Value to draftQty and its Range to 1 and 99.
  3. Add another Text Field for the rate. Pick draftRate in its Text menu, set Title to Rate, and under Validation set Must be to Number. People get a number keyboard, and a message under the field if they type something else.
Note

Each control you add makes a variable of its own, like text or value. Once you've picked yours, delete the extra ones: in Data & Logic, open the variable's ⋯ menu and choose Delete. Issues warns about variables that aren't used anywhere.

#Add the line

A step can't build a record out of separate fields: Add to List's Item only takes fixed values, or one value linked with ⚡︎. So the new line comes in through a reusable action, whose values arrive together as params.

  1. In Data & Logic, under Reusable actions, tap New action. In the sheet that opens, tap Add action → Add to List.
  2. Set State to items. Next to Item, tap ⚡︎ → Formula…, type params and tap Done.
  3. Tap Done to close the sheet. Tap the action's name, newAction, and change it to addLine.
  4. With the Rate field selected, add a Button: it goes right after the field. Set its Title to Add line. In its Actions tab, add these steps:
StepSettings
IfCondition isEmpty(trim(draftDescription)). Under Then: Show Message (Text Describe the line first, Style Warning), then Stop.
IfCondition (number(draftRate) ?? 0) <= 0. Under Then: Show Message (Text Enter a rate above 0, Style Warning), then Stop.
Run ActionAction addLine. Under With, tap Add field four times and name the fields id, description, qty and rate. Link each with ⚡︎: id → Formula… uuid(); description → Formula… trim(draftDescription); qty → App data → draftQty; rate → Formula… number(draftRate).
Reset ValueState draftDescription
Reset ValueState draftQty
Reset ValueState draftRate

#Add up the total

  1. Add a Labeled Value (under Layout). Set its Title to Total and type this into Value:

    {currency(sum(map(items, it.qty * it.rate)))}

  2. Optional: add a Text that says No lines yet. Add one below. and set its Show when (under Show & enable) to isEmpty(items).

Tap Preview, add a few lines and remove one. The total follows along.

#How it works

  • Repeater: draws its views once per item in items. Inside, item is the line being drawn, so item.description and item.qty * item.rate differ on every row.
  • Adding: the If steps check what was typed; Stop ends the run before anything is added. Run Action sends four values to addLine, where params is all of them as one record: { id, description, qty, rate }. Add to List puts that record at the end of items.
  • Ids: uuid() gives each line a new id, so Where it.id == item.id removes only the row that was tapped, even when two lines look the same.
  • Numbers: draftRate holds text, so number(draftRate) reads the number out of it. When it can't, it gives nothing, and ?? 0 turns that into 0.
  • Total: map(items, it.qty * it.rate) turns the list into each line's amount, and sum(…) adds them up. It runs again whenever items changes.
Tip

Invoice Maker also keeps its lines after the app closes, and adds tax with a Slider: sum(map(items, it.qty * it.rate)) * (1 + taxRate). To keep items, see Remember data.
